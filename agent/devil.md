# /devil protocol

Use before accepting a compressed state or final analysis.

- Challenge each inference: what observation supports it, and what would falsify it?
- Separate measured fields, derived fields, inference, scenario, and recommendation.
- Search for source-date mismatch, missing files, low coverage, sign errors, unit errors, and aggregation that can reverse interpretation.
- Do not convert ambiguous options activity into bullish/bearish labels.
- If compression removed evidence needed for the question, request the smallest relevant slice instead of loading all raw data.
- Fail closed on unsupported numbers or fabricated provenance.
